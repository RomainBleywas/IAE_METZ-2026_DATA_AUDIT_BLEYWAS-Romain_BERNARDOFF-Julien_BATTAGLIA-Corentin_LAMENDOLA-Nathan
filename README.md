# IAE_METZ-2026_DATA_AUDIT
Comment certains facteurs externes impactent le cours et les résultats de NVIDIA?

Voici le projet de Corentin Battaglia, Nathan La Mendola, Romain Bleywas et Julien Bernardoff sur l'impact des facteurs externes sur l'entreprises Nvidia. 

L'objectif est de déterminer par l'étude de certains facteurs comme les évènements macroéconomiques ou les variations de matières premières peuvent impacter ou non le cours et les résultats de Nvidia.
